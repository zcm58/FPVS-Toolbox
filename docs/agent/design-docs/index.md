# Design Docs

Design docs capture durable product and engineering beliefs that should shape
future FPVS Toolbox changes. They are not execution plans; use `docs/agent/exec-plans/`
for active implementation work.

Current entries:

- `core-beliefs.md`: agent-first operating beliefs for this repo.
- `PRODUCT_SENSE.md`: workflow priorities and future product direction.
- `DESIGN.md`: desktop design-system rules.
- `FRONTEND.md`: PySide6 implementation and validation boundaries.
- [Hardware, processing, and Studio direction](../architecture/hardware-pipeline-studio-roadmap.md):
  current capabilities and target architecture shared with product specs.
