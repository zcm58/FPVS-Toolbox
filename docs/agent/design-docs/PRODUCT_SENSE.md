# Product Sense

The [Toolbox product spec](../product-specs/fpvs-toolbox.md) owns the priority
of reproducible project-based processing, the Studio import and manual routes,
and acceptance for downstream tools. Use the [desktop design guide](DESIGN.md)
when changing what a lab member sees or does.

The [hardware, pipeline and Studio roadmap](../architecture/hardware-pipeline-studio-roadmap.md)
tracks future hardware profiles, method choices and experiment coverage.
New methods require validated profiles, persisted choices and explicit
invalidation of affected results.
