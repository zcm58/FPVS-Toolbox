# Product Specs

Product specs describe durable user-facing behavior and workflows. They are read
when changing features or GUI behavior, not for every code edit.

Current specs:

- `fpvs-toolbox.md`: active product scope and primary workflows.
- [Hardware, pipeline, and Studio direction](../architecture/hardware-pipeline-studio-roadmap.md):
  shared current/future contract for acquisition expansion and complete
  interoperability; feature plans must preserve its support-status distinctions.
